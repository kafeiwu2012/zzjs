# 上传与校验说明

本仓库整理了本次交流形成的全部 93 份对外交付文件，同时展开了 V2 系统、教师教学包和学生双岗位包，便于直接浏览和后续修改。逐项映射见 `materials-index.json`，表格入口见[资料总目录](资料总目录.md)。

## 下载和阅读

新使用者从首页三个 V2 包开始；需要单份资料时在 manuals、teaching/standalone、students/standalone、presentation 中查找。Word、PPT 可编辑；PDF 便于查看打印。较大的文件可点击 Raw／Download，或者使用首页的直接下载链接。

下载整个仓库使用 Code → Download ZIP；开发可 git clone。文件由 GitHub 仓库保存，与原工作区下载链接分开。

## 公开整理时的调整

1. 原交付文件均保留位置映射；公开整理未带上工作区缓存、运行数据或签名材料。
2. 早期 V1.1 两个 ZIP 内含上游库 SSL 示例 server.key，早期汇总包又嵌套这两个 ZIP；共四处出现已递归移除。归档内补充公开版说明，不覆盖原工作区下载文件。
3. 被清理的旧 ZIP 字节与旧哈希不同；旧校验记录保存在 original-checksums 路径，仅追溯使用。当前仓库文件统一以根 CHECKSUMS.sha256 校验。
4. 可浏览版系统与单份 Pi 手册采用教学包校正版：首次安装创建服务器 MQTT 账号，节点独立凭据在管理者批准时发放。既有完整交付 ZIP 保留交付快照；新学习以 manuals 中手册为准。
5. system/roomguard-v2/artifacts/SHA256SUMS_V2.txt 已针对可浏览工程的文档校正重新计算。

## 本机校验

在仓库根目录运行：

```bash
python3 tools/verify_materials.py
```

工具检查根清单、文件数量与哈希、ZIP 完整性，并递归排查私钥／运行数据文件名和明文私钥块。它不验证硬件、传感器性能或手机后台。

没有修改文件时应输出 PASS；修改自己的源码或文档后，与交付清单不同是预期结果，应另存新版本和新清单，而不是删除旧证据。

项目代码与第三方许可见工程目录和 THIRD_PARTY.md；本仓库不把软件构建、模拟截图或上传成功当成目标设备验收。
