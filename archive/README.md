# 历史资料

- `v1.0/`：初版系统、需求书、开发手册、早期 PPT 和演讲资料。
- `v1.1/`：Arduino 工程、动态界面、基板草案、相应手册与客户端。
- `combined-v1/`：早期整体汇总包。

新部署和教学优先使用仓库首页的 V2。不同版本的固件、接入方式和参数不要混用。

为公开上传，V1.1 的两个工程 ZIP 及引用它们的早期汇总 ZIP 已移除上游 ESPAsyncTCP SSL 示例 `server.key`；没有复制实际 Android 签名私钥或运行配置。被修改的归档内增加 `GITHUB_PUBLICATION_NOTE.txt` 说明。旧哈希文件放入 `original-checksums/`，归档内部旧清单亦只作为历史记录；校验当前上传文件使用仓库根目录 `CHECKSUMS.sha256`。
