# 教师后台操作手册 V2.0

## 1. 页面与权限

监控工作台：http://树莓派IP:8080/；大屏在后面加?screen=1；教师后台：http://树莓派IP:8080/teacher。首次教师账号admin，密码由安装时设置。教师后台仅teacher角色可进入，学生和只读账号不能调用管理接口。

教师：批准接入、绑定／停用、节点参数、服务、账号、显示、备份恢复。学生操作员：仅对授权节点确认／本次消音、查询历史。只读账号：查看授权状态／历史，不控制设备。公开大屏在可信局域网提供只读状态，因此节点授权范围不是对整个局域网的保密隔离。

## 2. 新节点接入

点击“生成10分钟接入码”，只在教师当前页面显示原码，不向学生公开服务器MQTT账号。给正在配网的一台ESP填写。它提交后出现在待接入列表，教师核对设备ID和板型，填写房间／楼层再批准。

一个有效房间名称只绑定一个活动设备，避免位置冲突。旧节点换板时先停用旧条目，历史保留，再批准新设备。相同设备重新配网会出现待批准申请，批准后轮换它自己的凭据。

停用会撤销后续MQTT登录凭据并拒绝服务器接收其遥测；已建立连接可能直到断开才重新认证，但服务器立即拒绝停用节点数据。停用不关闭本地报警，也不擦除历史。重新开放后仍需新接入码与配网。

## 3. 节点参数与告警

节点卡片可设置解除稳定时间1—300秒、常规上报5—60秒、硬件模板0或1，并显示期望配置版本／节点已应用版本。保存、发送、实际生效是不同状态，以回执和新上报版本为准。

离线配置保留期望值，重连后同步；消音只作用于在线节点当前事件，不能把旧消音排队到很久以后。默认5秒上报对应至少20秒离线门限；改变上报后按节点实际生效周期4倍且至少20秒判断，不依赖教师电脑时钟。

硬件模板0为原型ESP32分压10k/15k，1为V1.1基板参考20k/10k。软件只能改变换算与配置，不能改变实际电阻，必须核对实物。旧V1.1固件不支持新的上报／模板参数，应先升级V2。

监控页的确认表示已阅；本次消音保留红灯与异常；新增原因或新事件重新鸣叫；所有原因恢复并稳定N秒才解除。温湿度不触发告警。

## 4. 账号与学生分工

“账号与权限”新增至少3位的用户名，密码12—128位，选择teacher/operator/viewer。学生范围填设备ID，用英文逗号分隔，设备ID从节点列表复制，不填房间名。已有账号留空密码表示不修改。保存账号会注销现有会话，需要重新登录。

推荐两名学生各用自己的操作员账号，教师控制全局配置和服务。讲解学生可使用只读界面，硬件操作学生仅获准操作正在演示的设备。不要把教师密码投屏或写进PPT。

## 5. 终端与显示方案

终端首次打开监控页面自动登记。网页普通模式、大屏模式和EXE使用各自稳定终端ID；APK前台与原生后台共用安装实例ID。清理浏览器站点数据、卸载APK或换电脑会产生新ID，教师可重命名终端并分发方案。

显示方案包括标题、明暗主题、字号倍率0.85—1.4、每页1—24个节点、轮播5—120秒、页面查询2—10秒、默认历史窗口、楼层／房间范围、显示字段、异常优先与允许声音。方案约15秒内由前台拉取；新增节点无需重新打包各客户端。

范围筛选与显示停用是展示行为，不构成网络数据保密控制。禁用显示不关闭节点，也不取消APK原生后台监测；原生后台按该终端房间／楼层范围处理告警，并遵守允许声音设置。浏览器仍需本机点击启用声音，手机仍需系统允许后台、音量与Wi-Fi可达，服务器不能绕过。

大屏自动分页，普通网页／手机手动翻页。自适应不代表无限容量，实际节点数、图表查询量和终端数量应逐步压测。终端登记上限200条是管理防滥用措施，不是并发性能承诺；移除无用记录前关闭对应页面，否则会自动重新登记。

实时趋势只来自当前页面收到的最多60个采样。节点离线或服务器不可达时不伪造新数值，曲线冻结、显示过期状态。完整保留范围在历史页，单次CSV最多10000条，按时间分段导出。

## 6. 服务与维护

仅管理roomguard业务服务与mosquitto代理：查询状态、自启状态，启动／停止／重启／开机启用／取消自启。执行前输入服务名确认。涉及停服时页面会断开，排队返回不是已完成，应在重连后查看维护记录。

停止业务服务后网页无法启动自己，改用SSH执行sudo systemctl start roomguard。停止MQTT会使所有节点通信中断，但本地报警继续。后台不提供任意shell、任意文件读写、系统重装或网络接口随意改动。

可以读取最近60行指定服务日志，敏感字段脱敏。查看磁盘空间和数据库备份；选择备份输入RESTORE可请求恢复，先备份当前数据、验证备份、短暂停服、替换并启动。只接受本管理目录内V2数据库备份，不允许上传任意路径；MQTT密码文件不随数据库回滚，恢复后核对设备接入。

校时支持本机当前时间与手动时间。保留周期默认采样30天、事件与审计180天。重要记录先导出；到期清理由后台执行。没有RTC且无互联网时，断电后要重新确认时间。

## 7. 演示模式与实物模式

python -m tools.run_demo提供三模拟节点，横幅标注模拟数据。该模式不修改真实Mosquitto账号，不启停真实系统服务；服务维护按钮返回“模拟模式”，不能拿它当实际系统维护验收。

生产用安装服务启动，不设置DEMO或TEST_HELPER。实物最小验收为已有两节点，第三／第四节点可在准备好硬件后接入。测试资料中的多节点模拟不代表现场已装配相同数量板卡。

## 8. 每次比赛前检查

路由器与服务器地址稳定；两个实物节点供电与预热完成；后台时间、磁盘、代理、在线和参数版本正常；网页声音已手动启用；APK服务器和后台许可正确；保存一致性备份；核对操作员权限；异常测试与恢复方式已排练。

无法通过网页解决时按《树莓派新手部署与维护_V2》使用SSH／本地控制台。Web管理不是脱离操作系统的万能恢复工具。
