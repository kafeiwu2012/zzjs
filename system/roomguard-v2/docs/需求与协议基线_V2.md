# 系统需求与协议基线 V2.0

## 1. 范围

基于树莓派3B、Raspberry Pi OS Lite64-bit、MW305R局域网，支持经典ESP32与ESP8266独立采集及声光报警。最小实物基线为101／102两房间；设备清单、终端卡片和查询配置动态生成，可接第三节点及后续同协议设备。

软件构成：Arduino IDE两平台通用业务固件；Android5.1兼容配置网页；树莓派Web/API、MQTT和SQLite；教师、学生操作员、只读角色；网页、大屏、Windows10 x64 EXE、Android API22 APK；配置与运维文档、比赛PPT与双人讲稿。

## 2. 核心规则

温湿度只展示。MQ-2阈值或火焰触发对应房间本地声光，双方同时显示两个原因。网络不作为本地判断前提。确认只记录已阅，当前事件消音保留视觉告警，新原因或新事件重新鸣叫。全部原因恢复并稳定N秒解除，默认10秒，教师可配置。

设备身份固定MAC派生，位置由教师绑定。采样和事件记录当时房间信息；变更绑定不把旧采样伪装成新房间。停用保留历史。常规上报默认5秒，可设5—60秒；离线按实际生效上报周期4倍且至少20秒。服务器校时不改变单调计时逻辑。

配置带部署标识epoch、版本、命令ID和节点短期nonce，明确待下发、已发送、已生效、未确认或拒绝。消音必须匹配当前事件、节点在线，不保留MQTT过期命令。节点重启取消临时消音，保留常规配置。

## 3. 接入协议

教师生成10分钟144位随机码；ESP先通过手机配网，再HTTP POST /api/enroll提交：

```json
{"id":"rg-esp32-aabbccddeeff","code":"教师接入码","model":"ESP32","firmware":"2.0","capabilities":["dht11","mq2","flame","buzzer","rgb"]}
```

有效请求绑定该码与该ID，返回status=pending。教师批准并成功创建对应Mosquitto凭据后，同设备同有效码重试获得status=approved和mqtt_password。凭据只允许本设备主题；码到期或用于其他ID拒绝，停用设备拒绝。响应丢失可在该码有效期内由相同ID重试；过期需新码。

HTTP仅可信局域网，未提供TLS、硬件防伪或公网接入。设备唯一编号不能替代教师核对实际板卡。短期发放记录保存在受保护数据库并按时清理，备份也应保密。

## 4. MQTT与固件

MQTT1883，节点用户名=设备ID，密码独立；clean session，状态／回执QoS1，命令不retain。ACL模式为building/%u/state与ack可写、building/%u/command可读；server有统一订阅和下发权限。服务器通配订阅，但只接收已批准设备状态。

状态字段延续前版boot、seq、event_id、active、muted、reasons、smoke、flame、dht_ok、mq_ready、temperature、humidity、mq_raw、mq_voltage、config_version、control_nonce；新增config_epoch、clear_seconds、report_seconds、hardware_profile、model、firmware。是否生效同时核对部署标识、版本和实际参数，避免仅凭相同版本号误判。非有效DHT值为null，不伪造0。MQ未经标定为相对响应，不标准确ppm。

ESP32／ESP8266共用业务源码但分别编译，不能共用一个BIN。手机配网页面不等于OTA。本版支持固定五模块模板，能力声明用于管理记录，不自动加载任意新传感器驱动。

## 5. 主要HTTP接口

| 接口 | 权限与用途 |
| --- | --- |
| /api/login、/api/me、/api/logout | 账号登录、角色信息和退出 |
| /api/status | 局域网只读状态；带学生令牌时按其范围返回 |
| /api/enroll | 接入码验证与设备申请，不允许任意注册直接发凭据 |
| /api/nodes/{id}/confirm、silence | 教师或授权操作员，事件匹配与在线检查 |
| /api/nodes/{id}/config | 教师配置解除、上报与硬件模板 |
| /api/history、trend、export | 登录并检查节点范围；CSV每次最多10000条 |
| /api/manage/tickets、approve、disable、reopen | 教师设备生命周期 |
| /api/manage/users | 教师角色与范围管理 |
| /api/terminals/hello、/api/display | 终端登记、拉取非敏感显示方案 |
| /api/manage/profiles、terminals、terminal-delete | 教师显示方案及终端登记管理 |
| /api/manage/services、service、logs、jobs | 教师查询与受限维护 |
| /api/manage/backup、backups、restore | 教师一致性备份及受控恢复 |
| /api/time、settings | 教师校时与保留策略 |

令牌置Authorization: Bearer头，不放URL。账号密码PBKDF2哈希存储。所有重要管理操作写审计。显示范围不构成对公开大屏数据的保密控制。

## 6. 服务与故障

Web业务以roomguard用户运行，单worker；Mosquitto系统服务。root持有受限助手，只接受指定服务、账号和备份操作，无任意shell、路径或单元名称。维护排队与真实结果分开，审计记录可查询。系统网络或业务服务完全不可用时保留SSH恢复。

采样默认30天，事件／审计180天；可改保留期。服务器自启，设备自动重连，首版仍不补传完整离线事件与采样。无RTC／无互联网时需校时。数据库恢复不自动回滚MQTT密码文件。
