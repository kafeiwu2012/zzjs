# V2.0 测试与交付说明

日期：2026年11月8日。交付为软件实现、构建产物和开发部署资料；未在用户树莓派或ESP实物执行安装／烧录。

## 已实现

1. 动态设备注册与生命周期：短期接入码、待批准、独立身份和凭据、房间绑定、停用／重新开放、状态动态展示。
2. ESP32／ESP8266 Arduino工程：同一业务逻辑分别编译，Android5.1兼容AP配置网页，随机热点密码、运行后长按配置键、候选连接与失败回退、本地持久保存。
3. 教师Web后台：设备与参数、角色及学生范围、终端登记与显示方案、指定服务状态／启停／重启／自启、日志、备份／受控恢复、校时和保留策略。
4. 终端自适应：动态卡片、统计、历史与参数选项；主题、字号、字段、房间／楼层、分页／轮播、声音允许策略与历史窗口。APK原生后台共用终端身份并读取显示范围和声音允许设置。
5. 保留本地报警、确认／消音／解除、单调超时、配置回执、SQLite历史及CSV；新版PPT、双人逐页讲稿与教师排练资料。

## 仍保留的边界

不同芯片不能共用BIN；配网不是OTA；普通DO模块不具备完整断线自检；MQ响应不等于准确ppm；断网历史不完整补传；无RTC断电后可能需校时；数据库恢复不自动回滚MQTT密码文件；自适应不代表无限容量；系统仅面向可信局域网，未提供TLS及公网部署保证。

基板仍沿用V1.1引脚级审阅草案：每侧15针、针距2.54mm已知，两排针中心距与模块尺寸／脚序待核验，未完成走线和制造ERC／DRC签核，不含可下单Gerber。
